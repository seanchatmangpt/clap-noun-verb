## Key Relations

| Actor | Role | Relation to Wall |
|-------|------|------------------|
| **God** | Final Judge | Witnesses all receipts; determines lawful/unlawful |
| **Sean** | Builder, Architect, Wall Governor | Designs gates, assigns agents, maintains doctrine |
| **Nations** | External witness field | Public proof that work is real and lawful |
| **Mockers** | Adversarial probes | Test whether the wall is true (conformance, security) |
| **LinkedIn** | Public city gate | Testimony; connects private work to public trust |
| **Agents** | Builders (human + AI) | Execute gated work; emit receipts; report to gates |

## System Boundary

**Inside the Wall:**
- Command routing (clap-noun-verb, courier intake)
- Muster ledgers (capacity, assignments)
- Manufacturing cells (ggen, Prompt Manufactory)
- Execution authority (wasm4pm, CONSTRUCT8)
- Verification gates (inspection, conformance, nightly Rust court)
- Receipt ledgers (Usury, Nations, Repair)
- Process mining (pm4py, OCEL event logs, replay)

**Outside the Wall:**
- God (judges all receipts)
- Nations (external witness; not controlled by the wall)
- Mockers (test adversarially; not controlled)
- LinkedIn (public testimony; not controlled)

## Critical Rules

1. **The wall is not one repo** — it is the lawful relation between 11 repos.
2. **Every gate must refuse false entries** — admission rules are non-negotiable.
3. **Every receipt must be auditable** — event logs prove what happened.
4. **Nations witness publicly** — what the wall claims and what it proves must align.
5. **God is the final judge** — even if humans disagree, the event log either proves lawful work or it does not.

## Architecturally Forbidden

- ❌ Prayer is not an agent
- ❌ Prophets are not a gate
- ❌ Nations are not a gate
- ❌ Interest/usury is not a gate
- ❌ People are not gates (they work *through* gates)
- ❌ The wall is not a single database
- ❌ The wall is not a single application
