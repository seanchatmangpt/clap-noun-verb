# Build Artifacts & Internal Metadata

This directory contains build artifacts and internal metadata that are not part of the public documentation. These files support development workflows and tooling but are not intended for user consumption.

## Contents

| File | Purpose | Generated By |
|------|---------|--------------|
| `clap-capabilities.ttl` | RDF capability graph (Turtle format) | Build process / capability discovery |
| `claude-md-config.jsonld` | Claude Code configuration metadata (JSON-LD) | CLAUDE.md extraction / analysis tooling |
| `claude-md-context.jsonld` | Claude Code context metadata (JSON-LD) | CLAUDE.md extraction / analysis tooling |
| `test_results_raw.txt` | Raw test execution results / logs | Test suite runner |

## Notes

- **Do not edit manually** — these are regenerated by build processes
- **Do not commit changes** — consider adding to `.gitignore` if they update frequently
- **Not part of versioned docs** — user-facing documentation lives in parent `docs/` directory
