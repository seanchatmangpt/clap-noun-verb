3. validate-cli-structure.rq (2.9 KB)
   - Type: SELECT query (returns issues/violations when found)
   - Purpose: Validate noun-verb pattern conformance
   - Checks 7 conditions:
     1. No orphaned verbs (verbs without parent noun)
     2. All verbs named (cnv:hasVerbName present)
     3. All nouns named (cnv:hasNounName present)
     4. Verbs have exactly one parent noun
     5. Required args have valueType specified
     6. Verbs implement Send trait
     7. Verbs implement Sync trait
   - Sample Results: Detected 9 violations in verb-traits.ttl (incomplete definitions)
   - Use Case: CI/CD validation gate, pre-compilation checks, ontology QA

4. generate-trait-impls.rq (1.7 KB)
   - Type: SELECT query with aggregation
   - Purpose: Extract trait implementation requirements for code generation
   - Returns: resource URI/name, type (Noun/Verb), trait requirements, return type
   - Aggregates: Arguments per resource
   - Use Case: Generate impl blocks, verify trait bounds, create wrappers
   - Sample Results: 622 results including trait requirements for all nouns/verbs

5. generate-cli-spec.rq (1.3 KB)
   - Type: CONSTRUCT query (generates new RDF triples)
   - Purpose: Build normalized CLI specification for code generation
   - Output: RDF graph with spec: namespace predicates
   - Constructs: NounSpec and VerbSpec resources with spec: properties
   - Use Case: Feed into templates, version specs, export to JSON-LD
   - Features: URI generation using CONCAT and IRI functions

Example 3: Custom Query in Python
  from rdflib import Graph
  from rdflib.plugins.sparql import prepareQuery

  graph = Graph()
  graph.parse("ontology/cli-pattern.ttl", format="turtle")

  with open("queries/find-all-verbs.rq") as f:
      query = prepareQuery(f.read())

  for row in graph.query(query):
      print(f"{row.verbName} -> {row.returnType}")
