3. validate-cli-structure.rq - Check Pattern Conformance
================================================================================

Purpose:   Find violations of noun-verb pattern rules
Type:      SELECT query (returns issues when found)
Results:   9 violations in test data

Checks (7 total):
  1. Orphaned verbs      - Verb without cnv:belongsToNoun
  2. Unnamed verbs       - Verb without cnv:hasVerbName
  3. Unnamed nouns       - Noun without cnv:hasNounName
  4. Multiple parents    - Verb with 2+ parent nouns
  5. Untyped arguments   - Required arg without cnv:valueType
  6. Missing Send        - Verb without cnv:HasTraitBound cnv:Send
  7. Missing Sync        - Verb without cnv:HasTraitBound cnv:Sync

Output Columns:
  ?issue              - Title: "Orphaned verb: ex:AddVerb"
  ?affectedResource   - URI: ex:AddVerb
  ?description        - Details: "Verb does not belong to any noun"

Usage: CI/CD validation gate, pre-compilation checks, QA reports

================================================================================
COMMON QUERY PATTERNS
================================================================================

Pattern: Find by Name
  ?verb cnv:hasVerbName "status"@en .

Pattern: Optional Properties
  OPTIONAL { ?verb cnv:verbAbout ?description . }

Pattern: Count Relationships
  SELECT ?verb (COUNT(?arg) AS ?argumentCount)
  WHERE { ?verb cnv:hasArguments ?arg . }
  GROUP BY ?verb

Pattern: Find Missing Properties
  FILTER NOT EXISTS { ?verb cnv:belongsToNoun ?noun . }

Pattern: Case/When Mapping
  BIND(CASE
    WHEN ?argType = cnv:ArgumentType_Flag THEN spec:BoolFlag
    ELSE spec:Unknown
  END AS ?argumentKind)

Pattern: Construct URI
  BIND(IRI(CONCAT(STR(spec:), ?nounName, ":", ?verbName)) AS ?ref)

EXECUTION
================================================================================

Run All Queries:
  python3 run-sparql-queries.py

Run Single Query (Python):
  from rdflib import Graph
  from rdflib.plugins.sparql import prepareQuery

  graph = Graph()
  graph.parse("ontology/cli-pattern.ttl", format="turtle")

  with open("queries/find-all-verbs.rq") as f:
      query = prepareQuery(f.read())

  for row in graph.query(query):
      print(row.verbName, row.returnType)

Parameterized Query:
  from rdflib import Variable, Literal

  results = graph.query(query, initBindings={
      Variable("targetVerbName"): Literal("status")
  })

Export Results:
  # Convert SELECT results to CSV
  import csv
  with open("verbs.csv", "w") as f:
      writer = csv.writer(f)
      for row in graph.query(query):
          writer.writerow([row.verbName, row.returnType])
